## Running

### Python

- Run `python cors-server.py` to start a server
- Visit http://localhost:8000 in your browser
- To test on a phone find you ip address and navigate to http://<ip>:8000

Note: Using the IP address does not work on public networks (eg: university). Instead use a tunnel such as localtunnel or cloudflared which will give you a temporary url

### Node.JS

- Run `npx serve` to start a server
- Visit the provided address in your browser
- To test on a phone find you ip address and navigate to http://<ip>:8000

Note: Using the IP address does not work on public networks (eg: university). Instead use a tunnel such as localtunnel or cloudflared which will give you a temporary url
